# Isaac's Minesweeper Script

Панель управления для **Isaac's Minesweeper** в Roblox с современным GUI и набором инструментов для автоматизации работы с игровым полем.

> **Версия скрипта:** 10.1

## Возможности

### Современный интерфейс

- тёмный современный дизайн;
- вкладки `Main`, `FlagLights`, `AutoFlag` и `Macro`;
- единый стиль кнопок и переключателей;
- адаптивное положение главного окна;
- сворачивание панели в компактную кнопку;
- прокручиваемый контент для небольших экранов.

### Player Speed

Изменение скорости персонажа через слайдер.

- диапазон: `8–100`;
- `Custom speed` — включение пользовательской скорости;
- `Reset` — возврат к стандартной скорости;
- значение скорости сохраняется после респавна во время текущей сессии.

### AFK Farm

Автоматически выбирает ближайшую подходящую закрытую безопасную клетку и перемещает персонажа к ней.

- ищет ближайшую неоткрытую клетку;
- не использует `PathfindingService` в основном цикле движения;
- проверяет появление новых целей, когда доступных клеток больше нет;
- останавливает персонажа при выключении функции.

### AutoFlag

Автоматически устанавливает флаги на клетках на основе состояния игрового поля.

#### Smart Mode

Использует информацию об открытых клетках, количестве мин и соседних клетках для поиска клеток, которые можно пометить.

#### Hard Mode

Быстрый режим автоматической установки флагов.

- ограничивает поиск областью `WORK RADIUS`;
- выбирает ближайшую обнаруженную мину;
- использует кэш обнаруженных мин;
- обновляет кэш только при изменениях поля;
- уменьшает лишние задержки между попытками установки флага.

### Mine Protection

При приближении игрока к обнаруженной мине автоматически пытается установить на неё флаг.

Расстояние защиты настраивается отдельным слайдером.

### Remove Wrong Flags

Автоматически снимает флаги с клеток, которые не являются минами.

### Flag Lights

Подсвечивает клетки в зависимости от их состояния:

- красный — обнаруженная мина;
- оранжевый — мина с установленным флагом;
- фиолетовый — неправильный флаг.

### Macro

Позволяет назначать клавиши для основных функций:

- открытие/скрытие меню;
- включение AutoFlag;
- включение Flag Lights.

## Как использовать

### 1. Откройте Roblox и зайдите в Isaac's Minesweeper

Запустите игру и дождитесь полной загрузки игрового поля.

### 2. Запустите Lua-скрипт

Скрипт находится в корне репозитория:

`isaacs-minesweeper-script.lua`

Актуальная версия доступна по адресу:

```text
https://raw.githubusercontent.com/Seven-Aspects/isaacs-minesweeper-script/refs/heads/main/isaacs-minesweeper-script.lua
```

Для загрузки из raw-адреса в среде, поддерживающей `loadstring`, можно использовать:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Seven-Aspects/isaacs-minesweeper-script/refs/heads/main/isaacs-minesweeper-script.lua"))()
```

> Скрипт рассчитан на среду, которая поддерживает выполнение загруженного Lua-кода и работу с Roblox API. Не используйте сторонние загрузчики, которым вы не доверяете.

### 3. Откройте меню

После запуска появится панель **Isaac's Minesweeper**.

По умолчанию меню можно открыть/скрыть клавишей `RightControl`.

### 4. Настройте Player Speed

Во вкладке `Main`:

1. передвиньте слайдер на нужную скорость;
2. включите `Custom speed`;
3. для возврата к стандартному значению нажмите `Reset`.

### 5. Настройте AFK Farm

Во вкладке `Main` включите `AFK Farm`.

После этого скрипт начнёт искать ближайшие подходящие закрытые клетки. Если доступных целей нет, персонаж остановится и продолжит проверять поле до появления новых клеток.

### 6. Настройте AutoFlag

Откройте вкладку `AutoFlag`.

Можно выбрать:

- скорость работы;
- `Smart Delay`;
- `Hard Mode`.

Для максимально быстрого режима установки флагов используйте `Hard Mode`.

### 7. Настройте защиту

Во вкладке `Main` доступны:

- `Mine protection`;
- `Remove wrong flags`;
- расстояние `Mine Protection`.

### 8. Настройте подсветку

Во вкладке `FlagLights` можно включить подсветку и изменить используемые цвета.

### 9. Настройте горячие клавиши

Во вкладке `Macro` нажмите на нужное действие и затем нажмите желаемую клавишу.

## Основные настройки

Основные параметры находятся в верхней части Lua-файла, включая:

- `WORK_RADIUS`;
- `MINE_PROTECTION_DISTANCE`;
- `AUTOFLAG_SPEED`;
- `AUTOFLAG_SMART_DELAY`;
- `AUTOFLAG_HARD_MODE`;
- параметры Player Speed;
- цвета подсветки.

## Структура интерфейса

### Main

- `Player Speed`;
- `AFK Farm`;
- `Work Radius`;
- `Mine Protection`;
- `Remove Wrong Flags`.

### FlagLights

- включение подсветки;
- горячая клавиша;
- цвета мин, отмеченных мин и неправильных флагов.

### AutoFlag

- включение AutoFlag;
- скорость;
- Smart Delay;
- Hard Mode.

### Macro

- настройка горячих клавиш.

## Производительность

Hard Mode оптимизирован для частого обновления состояния поля. Вместо полного пересканирования всех клеток на каждом проходе используется кэш мин, который обновляется при изменениях соответствующих объектов или атрибутов.

Также поиск ограничивается текущим `WORK_RADIUS`, что уменьшает количество проверок на больших игровых полях.

## Требования и совместимость

Скрипт зависит от конкретной структуры игры, включая:

- папку `workspace.tiles`;
- атрибуты клеток, например `mine`, `flagged`, `cleared` и `mines`;
- remote, используемый для установки и снятия флагов.

Если разработчики игры изменят структуру объектов, атрибуты или remote-события, скрипт может потребовать обновления.
