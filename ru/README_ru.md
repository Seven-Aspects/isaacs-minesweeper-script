# Isaac's Minesweeper Script

Улучшенная панель управления для **Isaac's Minesweeper** в Roblox с удобным GUI и набором инструментов для автоматизации работы с игровым полем.

> Текущая версия: **v10.1 Fast Hard**

## Возможности

### 🎨 Современный интерфейс

Панель переработана в тёмном современном стиле:

- аккуратные карточки и вкладки;
- единый стиль переключателей и кнопок;
- улучшенные отступы и выравнивание;
- адаптивное позиционирование панели;
- отдельная компактная кнопка для сворачивания;
- настройки разделены по функциональным вкладкам.

### ⚡ Player Speed

Позволяет изменять скорость персонажа через отдельный слайдер.

- диапазон скорости: `8–100`;
- `Custom speed` для включения/выключения пользовательской скорости;
- `Reset` для возврата стандартной скорости;
- выбранная скорость повторно применяется после респавна персонажа.

### 🚜 AFK Farm

Автоматически ищет ближайшие подходящие закрытые клетки и перемещает персонажа к ним.

- выбирает ближайшую доступную клетку;
- не использует тяжёлый `PathfindingService` для основного движения;
- проверяет появление новых клеток, когда текущих целей больше нет;
- прекращает движение при отключении функции.

### 🚩 AutoFlag

Автоматическая установка флагов на основе состояния игрового поля.

Доступны два режима:

#### Smart Mode

Использует информацию об открытых клетках, количестве мин и соседях, чтобы определить клетки, которые можно безопасно пометить.

#### Hard Mode

Быстрый режим автоматической установки флагов.

- работает в пределах `WORK RADIUS`;
- выбирает ближайшую обнаруженную мину;
- использует кэш списка мин вместо полного пересканирования поля на каждом шаге;
- уменьшает лишние задержки между попытками;
- оптимизирован для высокой частоты установки флагов.

### 🛡 Mine Protection

При приближении персонажа к обнаруженной мине автоматически пытается установить на неё флаг.

Расстояние защиты регулируется отдельным слайдером.

### 🧹 Remove Wrong Flags

Автоматически снимает флаги с клеток, которые не являются минами.

### 💡 Flag Lights

Подсвечивает клетки разными цветами в зависимости от их состояния:

- красный — обнаруженная мина;
- оранжевый — мина с установленным флагом;
- фиолетовый — неправильный флаг.

Для подсветки используется верхняя визуальная поверхность над клеткой.

### ⌨️ Macros

Позволяет назначать горячие клавиши для основных действий:

- открытие/скрытие меню;
- включение AutoFlag;
- включение Flag Lights.

Клавиши можно изменить непосредственно во вкладке `Macro`.

## Вкладки

### Main

Основные настройки:

- Player Speed;
- AFK Farm;
- Work Radius;
- Mine Protection;
- Remove Wrong Flags.

### FlagLights

Настройка подсветки клеток и горячей клавиши.

### AutoFlag

Настройка скорости AutoFlag, Smart Delay и Hard Mode.

### Macro

Настройка горячих клавиш.

## Управление

Панель можно перемещать мышью за верхнюю область окна.

Кнопка `−` сворачивает меню в компактный круглый индикатор. Повторное нажатие открывает меню обратно.

Горячие клавиши настраиваются во вкладке `Macro`.

## Настройка

Основные значения находятся в верхней части Lua-скрипта в блоке `SETTINGS`.

Там можно изменить:

- рабочий радиус;
- скорость AutoFlag;
- задержки;
- расстояние Mine Protection;
- цвета подсветки;
- параметры Player Speed.

## Производительность

Версия `v10.1 Fast Hard` в первую очередь оптимизирует `Hard Mode`.

Основная идея оптимизации — не выполнять полный поиск по всем клеткам на каждом проходе. Вместо этого используется кэш обнаруженных мин и ограничивается область поиска текущим рабочим радиусом.

Это уменьшает количество лишних операций при большом игровом поле.

## Важно

Скрипт рассчитан на конкретную структуру игровой логики и наличие объектов/атрибутов, используемых игрой, включая папку `tiles`, атрибуты клеток и remote для флагов.

При изменении самой игры названия объектов, атрибутов или формат remote-вызовов могут потребовать адаптации.
